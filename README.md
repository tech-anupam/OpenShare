### Features

| Feature | Highlight |
|---|---|
| 🖥️ **macOS Window Studio** | Unified drag-and-drop file upload & live Markdown editor |
| 🔐 **Client-Side AES-256** | Zero-knowledge PBKDF2 encryption (100k rounds) |
| 🎬 **Discord Video Embeds** | Native inline video player cards for Discord, Telegram & X |
| ⚡ **Direct Plaintext Raw** | Fetch code and pastes directly via `/[id]/raw` with `curl` |
| ⏳ **Self-Destruction** | Configurable auto-delete (1h, 6h, 24h, 7d) with automated cleanup |
| 🚀 **Attachment Downloads** | Direct stream download without triggering browser video player tabs |
| 👤 **Zero Accounts** | No sign-ups, no cookies, no tracking |
