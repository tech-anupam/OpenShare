### Highlights

- **macOS Window Studio**: Unified file upload and Markdown editor inside a native macOS glass frame.
- **Client-Side AES-256-GCM**: Zero-knowledge encryption with PBKDF2 (100,000 iterations). Passwords never leave your device.
- **Discord & Social Media Embeds**: Inline video player cards for Discord, Telegram, and Twitter/X.
- **Direct Plaintext Raw URLs**: Fetch pastes and code files directly via `/[id]/raw` with `curl` or scripts.
- **Auto-Destruction**: Configurable self-destruct timers (1 hour to 7 days) with automated cleanup.
- **Zero Accounts**: No sign-ups, no cookies, no tracking. Upload, get your link, and share.
